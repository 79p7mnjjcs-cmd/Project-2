# План: список дел на неделю

## Цель
Сделать простую веб-страницу для дел на текущую неделю: пользователь вводит дело, добавляет его в список и может удалить. Данные сохраняются в localStorage этого браузера и остаются после перезагрузки. Список общий на неделю, без распределения по дням и автоматического сброса.

## Что не делаем
- Регистрацию, сервер, базу данных и синхронизацию между устройствами.
- Календарь, сроки, уведомления, повторяющиеся задачи и историю недель.
- Редактирование, отметки выполнения, категории и перетаскивание.
- Сторонние библиотеки и сборку проекта.

## Шаги и проверка
1. Сохранить текущий приветственный экран, его оформление, анимацию появления и кнопку с конфетти. Под ним добавить раздел «Дела на неделю»: подписанное поле ввода, кнопку «Добавить» и сообщение для пустого списка.
   Проверка: открыть страницу на компьютере и при ширине 360 px; приветственный экран сохранён, анимация и конфетти работают, раздел дел доступен ниже по странице; текст читается, элементы помещаются без горизонтальной прокрутки, поле имеет доступную подпись.
2. Добавить создание дел кнопкой и клавишей Enter. Обрезать пробелы по краям, не добавлять пустые строки; после добавления очищать поле и оставлять в нём фокус. Каждому делу присваивать уникальный идентификатор. Показывать введённый текст как текст, без исполнения HTML.
   Проверка: добавить несколько дел обоими способами; проверить пустой ввод, пробелы, одинаковые названия и строку с HTML-разметкой. Каждое непустое дело появляется один раз за отправку, разметка отображается буквально.
3. Добавить кнопку удаления у каждого дела.
   Проверка: удалить дело из середины списка, затем одно из двух одинаковых по названию, затем все остальные. Удаляется только выбранная запись; для пустого списка возвращается сообщение.
4. Добавить сохранение списка в localStorage после каждого изменения и загрузку при открытии страницы. Проверять формат сохранённых данных. При повреждённых данных или недоступном хранилище сохранять работоспособность страницы и показывать понятное сообщение о проблеме сохранения.
   Проверка: добавить дела и перезагрузить страницу; удалить дело и снова перезагрузить. Проверить повреждённые данные и отказ доступа к хранилищу: страница не падает, добавление и удаление работают в текущей сессии.
5. Проверить весь сценарий и подготовить изменения для просмотра.
   Проверка: добавить дело → перезагрузить → удалить → перезагрузить; пройти интерфейс клавишами Tab и Enter, проверить видимость фокуса и отсутствие ошибок в консоли. Проверять сохранение на одном и том же адресе в одном браузере; локальный запуск через HTTP предпочтителен, поскольку поведение localStorage для file:// зависит от браузера.

## Когда считаем готовым
- Добавление кнопкой и Enter, удаление и пустое состояние работают.
- Дела сохраняются после перезагрузки при доступном localStorage; сбои хранения не ломают интерфейс.
- Пользовательский ввод отображается безопасно, одинаковые записи удаляются независимо.
- Страница удобна на телефоне и компьютере и доступна с клавиатуры.
- Весь интерфейс, стили и логика находятся в index.html без внешних зависимостей.
- Перечисленные проверки пройдены, результат сообщён пользователю.
