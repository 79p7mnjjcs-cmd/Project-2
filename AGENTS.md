# Правила работы с проектом

## Проект
Простое веб-приложение учёта личных расходов: пользователь добавляет траты и просматривает список. Данные хранятся в браузере в localStorage.

## Стек
HTML5, CSS3 и обычный JavaScript без сборки. Не подключать фреймворки, сторонние библиотеки и зависимости через CDN.

## Правила
- Комментарии в коде писать по-русски.
- Папку assets и её содержимое не изменять, не удалять и не перемещать.
- Длинные функции разбивать на небольшие функции с одной понятной задачей.
- Не предлагать и не добавлять серверную базу данных.
- Не добавлять авторизацию и регистрацию.
- Сохранять данные на фронтенде в localStorage.

## Проверка после изменений
- Открыть приложение в браузере и убедиться, что интерфейс отображается и в консоли нет ошибок.
- Добавить новую трату с корректными данными и проверить, что она появилась в списке.
- Перезагрузить страницу и убедиться, что добавленная трата сохранилась.
- В описании PR указать выполненные проверки; если проверка недоступна, явно сообщить об этом.

## Команды для PR
Выполнять из локального клона репозитория с настроенной авторизацией GitHub CLI. Заменить имя ветки, заголовок и описание на соответствующие задаче. Добавлять в коммит только файлы задачи.

```sh
git switch -c feature/expense-change
git status --short
git diff --check
git diff
# Повторить команду для каждого изменённого файла задачи.
git add -- путь/к/файлу
git diff --cached
git commit -m "Краткое описание изменений"
git push -u origin HEAD
gh pr create --base main --title "Краткое описание изменений" --body "Что изменено и какие проверки выполнены"
```
